# genesis-ear — the GENESIS ear module (v1.0.0)

Live Persian speech recognition for GENESIS on Windows.

- **Engine:** faster-whisper `small`, int8, CPU (open-source, free).
- **Model:** downloaded once from Hugging Face on first activation into
  `models/fw-small/` (~470 MB, free), then fully offline.
- **Install dependency (pinned):** `faster-whisper==1.2.1`
  `sounddevice==0.5.2` — installed by the build scripts
  (`installer/build_on_windows.ps1` step 8b, same in `.bat`, same in the
  cloud `build.yml`). CPU-only; no GPU needed.
- **Contract:** the factory class is `EarListener` (see `ear_listener.py`).
  Every public method returns a result dict with `"ok"` — expected
  failures (no mic, model not yet downloaded, silence) are `ok: False`,
  never exceptions.
- **Dialogue input:** the runtime wires `start(on_utterance)` so each
  transcribed utterance is appended to `runtime/state/ear_utterances.jsonl`
  — the dialogue-input channel the conversation loop consumes.
- **Updates:** this module is delivered and updated by the in-app
  auto-updater (`runtime/modules/updater.py`) from the version feed.
  The feed entry is generated by
  `runtime/modules/tools/make_module_package.py`.
