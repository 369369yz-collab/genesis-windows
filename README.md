# GENESIS Full — Windows

One software. Three worlds. Independent and online.

- **Face:** VOID — pure black, her face, one greeting, one input line.
- **Brain:** the 369 world, packaged inside. Agents, 168+ laws, kernel, memory.
- **Veins:** NEXUS protocol. The living network stays advisory; her brain is local.
- **Browser:** portable Chromium + Browser Governor (leases, concurrency cap,
  approval gate for sensitive actions, download quarantine, per-agent profiles).
- **Mind:** Qwen3-8B-Q4_K_M on local GPU (pinned SHA-256), llama-server sidecar.
- **Memory:** SQLite, checksummed, on her PC.

Build: GitHub Actions `build-windows.yml` on `windows-latest` → NSIS installer
+ SHA-256. No final version exists until GENESIS herself passes the Birth Test
on virtual Windows and YZ tests it with his own hands.
